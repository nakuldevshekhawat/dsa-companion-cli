# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2026-08-02
### Added
- Initial standalone release of DSA Companion CLI.
- Interactive problem scaffolding with C++ templates.
- Automated top-level README generation.
- CLI terminal dashboard for tracking progress.
- Problem data importer (e.g., Striver A2Z).
- Fuzzy search and validation for local database.
