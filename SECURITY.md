# Security Policy

## Supported Versions

Currently, only the latest version of DSA Companion CLI is supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within this project, please DO NOT open a public issue. We ask that you report it privately to the maintainers to give us time to address it before public disclosure.

For sensitive security issues, please contact the repository maintainer through the contact information available on GitHub. We will acknowledge your report and keep you updated on our progress toward a fix.
